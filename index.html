Custom software

The pipeline tools used for SINE detection, subfamily classification, tribe clustering, and orthology assessment are maintained as separate repositories:

  • sear2k — SINE copy detection (SSEARCH36-based genome scan)
  • SubFam — subfamily consensus building
  • FaSort10 / asSINEment — subfamily assignment voting
  • SINE_orth_loc — orthologous locus assessment
